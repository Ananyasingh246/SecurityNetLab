# Lab 01 - Understanding Virtualization

## Objective

Understand how virtualization works before creating the first virtual machine.

## What I Learned

- A virtual machine uses virtual hardware presented by the hypervisor.
- The hypervisor allocates CPU, memory, storage, and networking from the host computer.
- Virtual CPUs are scheduled on the host's physical CPU instead of being dedicated hardware.
- Memory is allocated from the host and must be shared carefully when multiple VMs run at the same time.
